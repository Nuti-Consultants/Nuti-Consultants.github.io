Observability at Scale

Instrumenting network functions so that a protocol-level failure is visible as a protocol-level signal, and so that the alerts that remain are the ones worth waking someone for.

The problem

Generic infrastructure monitoring tells you a container restarted. It does not tell you that a peer is silently dropping user-plane packets, that a session was reaped because it went stale rather than because it ended, or that a cache refresh failed quietly at boot and the next hour of routing decisions will be wrong. Those are protocol events, and they have to be instrumented where the protocol is handled.

What we built

Metrics inside the network function

Instrumentation designed with the protocol in mind rather than bolted on afterwards: session counters broken down by destination, peer and APN; cache gauges exported at scrape time instead of being sampled on a timer; explicit counters for the paths that normally fail silently — datapath drops, rate-limited deferrals, sequence mismatches, failed background refreshes.

A gap scan, not a wish list

Rather than adding metrics as incidents suggested them, we walked the code systematically for branches that could be taken without leaving a trace, and instrumented those. Every silent path either got a counter or a documented reason it did not need one. That exercise is what turns a dashboard from decorative into diagnostic.

Active probing at the protocol layer

Synthetic traffic exercising the real control plane continuously, so a path that has quietly stopped working is detected before a subscriber finds it. Black-box probes that only check whether a port answers will not catch this.

How it holds up

The measure of an alerting system is not how much it covers but how much of it people trust. The work included deliberately removing alerts — the ones that fired without anyone acting, and the ones whose runbook had become “check whether it clears” — alongside clear ownership for the ones that stayed, and long-term metric storage so capacity questions can be answered from evidence.
